# Blog Auto-Tagger

Suggests up to five approved tags for a blog post and sends uncertain posts to an editor for review.
Internship project: "Automated Content Tagging for Blogs".

## Setup (Windows, PowerShell)

```powershell
py -3.13 -m venv C:\Users\vinoc\.venvs\blog-tagger
& C:\Users\vinoc\.venvs\blog-tagger\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```
